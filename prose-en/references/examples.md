# Examples and edge cases

Copyright © 2026 Luděk Sušický

These examples express this skill's style. They do not identify the authorship of the original text.

| Pattern | Before | After | Reason |
|---|---|---|---|
| Binary contrast | This is not just a backup tool — it's a peace of mind. | The tool backs up your work every hour. | State the concrete behaviour |
| Throat-clearing | Here's the thing: the deadline is Friday. | The deadline is Friday. | The opener delayed the point |
| Colon reveal | The detail that changes everything: the cache is shared. | The cache is shared between users, which changes everything. | A plain sentence beats the dramatic fragment |
| Superficial analysis | We shipped the export, underscoring our commitment to quality. | We shipped the export, so reports now download as PDF. | The consequence, not the commentary |
| Weasel attribution | Experts agree that daily standups fail. | The 2019 Standish report found standups fail on distributed teams. | Name the source or cut the claim |
| Fake-strong verb | The dashboard serves as a centralized hub for analytics. | The dashboard shows traffic, conversions and churn. | Direct verbs; concrete nouns |
| Importance puffery | This launch marks a pivotal moment for the team. | This is the team's first paid product. | The fact, not the ceremony |
| Fake-profound kicker | In the end, code is a conversation with the future. | Ship the fix this week; the dashboard shows the rest. | End on the concrete point |
| Empty adverb | The migration is simply faster. | The migration takes 4 minutes, down from 40. | A number beats the adverb |

## Passages to keep

- "I think the model is wrong, but I can't prove it yet.": real uncertainty survives the edit.
- "My grandmother taught me this trick.": a personal aside that carries context stays.
- "Maybe. Probably not.": the writer's spoken rhythm; do not professionalize it.
- Ranges such as "2020–2026" and "pages 22–23": the en dash is not a clause-connecting dash.
- Quoted slogans and cited sentences: outside the scope; never edit them to fit the style.

## Detect-only output shape

For a detection request, report findings without rewriting:

```
Binary contrast: "not just a backup tool — it's a peace of mind" → state the behaviour
Colon reveal: "The detail that changes everything:" → plain sentence
```

Each row names the pattern, quotes the line and suggests the fix in a few words. No score, no authorship guess.
